# The languages used in this file are:

#### HTML (HyperText Markup Language): This is the core language defining the structure and content of the webpage.

### CSS (Cascading Style Sheets):
###### External CSS/Framework: Tailwind CSS is imported via a CDN, providing the utility classes for styling and layout.
###### Internal CSS: A <style> block contains custom CSS rules to define the font, background, and styling for elements like section-title and scroll-button.

#### JavaScript: Used in the <script> block at the end of the body to add interactivity, specifically for toggling the mobile menu and implementing smooth scrolling for navigation links.
